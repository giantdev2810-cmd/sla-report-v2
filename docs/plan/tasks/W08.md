## Approved proposal

- Approval: the user requested an inspection-output retention rule, then specified
  "lưu output raw luôn". The subsequent "duyệt" approved the revised W08 proposal
  with local raw bodies, output, metadata, the ignore entry, and Git delivery.
- Goal: retain the evidence needed to examine an API observation without another
  live call, including the original response bodies and failed responses.
- Scope: `.gitignore`, AGENTS, PLAN, STATE, and this record. Documentation/ignore
  only; no script changes, API access, old-output reconstruction, or PR merge.
- Decisions: store each future run at
  `.local/inspect/<task-id>/<UTC-timestamp>/`, ignored by Git. Keep full unchanged
  bodies separate from complete sanitized inspection output and metadata. This
  preserves detail locally while the public repository contains only sanitized
  evidence; reviewers on another machine do not automatically receive raw files.
- Metadata: timestamp, endpoint, non-sensitive parameters, HTTP status, and the
  raw-body filename. No authorization header, configured token, or raw cursor in
  metadata/output; cursors inside raw response bodies remain in private files.
- Failure behavior: create the directory before requests, save evidence as each
  completes, and record final outcome. Stop on save failures. Transport failures
  have no invented body/status. Do not retry just to recreate missing output.
- Applicability: future approved inspections. Existing summary-only scripts need
  separately approved capture support before another live run. W08 does not
  retroactively claim that raw bodies from T03 were retained.
- Acceptance: AGENTS and PLAN agree on the rule; raw inspection paths are ignored;
  task records can identify local evidence while sharing sanitized summaries.
- Estimate: 10 minutes including candidate review.
